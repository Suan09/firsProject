# Django Project

Учебный проект на Django.

## 📌 О проекте

Этот проект создан для практики разработки на Django.  
В проекте есть следующие модули:

- Приложение `cars`
- Приложение `users`
- Шаблоны Django
- Конфигурация проекта в папке `conf`
- Файл зависимостей `requirements.txt`

---

## 🛠️ Технологии

Проект использует:

- Python 3.12.7
- Django 6.0.2
- HTML-шаблоны

Библиотеки указаны в `requirements.txt` :contentReference[oaicite:1]{index=1}

## 💾 Установка

1. Клонировать репозиторий

-bash
git clone https://github.com/Suan09/firsProject.git
cd firsProject

2. Создать и активировать виртуальное окружение
python -m venv venv
venv\Scripts\activate

3. Установить зависимости
pip install -r requirements.txt
